# 🎨 Anything\_QR

**Transform your imagination into scannable art!**
*Anything\_QR* is a quirky and delightful QR code generator that lets you encode anything you fancy—be it text, emojis, or even ASCII art—into a QR code. Whether you're looking to share a secret message, a favorite quote, or just some random fun, Anything\_QR has got you covered!

🚀 **Live Demo:** [Try it here!](https://anythingqr.streamlit.app/)

---

## ✨ Features

* 🎯 **Versatile Input:** Encode plain text, emojis, ASCII art, or any string you desire.
* 🎨 **Creative Freedom:** Let your imagination run wild—if you can type it, you can QR it!
* ⚡ **Instant Preview:** See your QR code come to life in real-time.
* 📥 **Easy Download:** Save your masterpiece as an image with a single click.

---

## 🛠️ Installation

To run Anything\_QR locally, ensure you have Python installed, then follow these steps:

1. **Clone the repository:**

   ```bash
   git clone https://github.com/Rktim/Anything_QR.git
   cd Anything_QR
   ```

2. **Create a virtual environment (optional but recommended):**

   ```bash
   python -m venv env
   source env/bin/activate  # On Windows: env\Scripts\activate
   ```

3. **Install the dependencies:**

   ```bash
   pip install -r requirements.txt
   ```

4. **Run the Streamlit app:**

   ```bash
   streamlit run qr.py
   ```

---

## 📦 Dependencies

* `streamlit==1.36.0` – For building the interactive web interface.
* `qrcode==7.4.2` – To generate QR codes from your input.
